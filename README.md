# 연결 실패 오답노트 (웹)

개념은 알았는데 문제와 연결하지 못한 문항을 기록하는 웹앱입니다. `index.html` 파일 하나로 동작합니다.

- **과목 탭**: 생물 내용학 · 생물교육론 · 교육학. 과목마다 단원 목록이 들어 있고, 단원을 고르면 세부 주제 후보가 뜹니다(직접 입력도 가능)
- **단원으로 거르기**: 위쪽 단원 선택으로 빠른 정리·전체 양식·다시 읽을 개념·복습을 한 단원만 볼 수 있음
- **빠른 정리**: 단원 · 세부 주제 · 판단 규칙 · 쓰는 상황 · 유형 · 출처. 같은 규칙이 또 나오면 "출처 추가"
- **유형 기호**: 내용학은 A~N(실험 해석 유형), 생물교육론·교육학은 P~T(사례→이론, 개념 구분, 단계·순서, 학자·용어, 적용)
- **전체 양식**: ①~⑤ 칸. ⑤ 판단 규칙을 빠른 정리에 바로 넣을 수 있음
- **실수·다시 읽기**: 실수 습관(반복 횟수), 다시 읽을 개념(체크)
- **복습**: 쓰는 상황을 보고 판단 규칙 떠올리기. 헷갈린 규칙이 다음에 먼저 나옴
- **백업 저장 / 불러오기**: 전체 기록을 JSON 파일로 저장·복원

## 저장 방식

| 방식 | 설정 | 특징 |
|---|---|---|
| 이 기기에만 저장 (기본) | 없음 | 그 브라우저에만 저장. 방문 기록을 지우면 사라질 수 있으니 백업 저장 권장 |
| GitHub 동기화 | 아래 2~4단계 | 내 **비공개** 저장소의 `wrongnote.json` 파일에 저장. 휴대폰·PC에서 같은 기록. 저장할 때마다 커밋이 남아 자동 백업 |

GitHub 동기화를 켜도 이 기기에 먼저 저장하므로, 인터넷이 끊겨도 계속 쓸 수 있고 연결되면 자동으로 올라갑니다.

---

## 1단계: 앱을 GitHub Pages로 올리기 (공개 저장소)

1. GitHub에 로그인 → 오른쪽 위 **+** → **New repository**
2. 이름 예: `wrongnote` → **Public** → **Create repository**
3. **uploading an existing file** 링크 → `index.html`, `README.md`를 끌어다 놓기 → **Commit changes**
4. 저장소 **Settings** → 왼쪽 **Pages** → Source: **Deploy from a branch**, Branch: **main** / **(root)** → **Save**
5. 1~2분 뒤 같은 화면 위쪽에 주소가 나옵니다: `https://<내아이디>.github.io/wrongnote/`

여기까지만 해도 "이 기기에만 저장" 방식으로 바로 쓸 수 있습니다. 이 저장소에는 앱 코드만 있고 기록은 들어가지 않습니다.

## 2단계: 기록을 담을 비공개 저장소 만들기

1. 다시 **+** → **New repository**
2. 이름: `wrongnote-data` → **Private** 선택
3. **Add a README file** 체크 (저장소가 비어 있으면 안 됩니다) → **Create repository**

## 3단계: 토큰 만들기 (이 저장소만 고칠 수 있는 열쇠)

1. 오른쪽 위 프로필 사진 → **Settings** → 왼쪽 맨 아래 **Developer settings**
2. **Personal access tokens** → **Fine-grained tokens** → **Generate new token**
3. 이렇게 고르세요.
   - Token name: `wrongnote`
   - Expiration: 시험 뒤까지 넉넉하게 (예: 90 days)
   - Repository access: **Only select repositories** → `wrongnote-data` 하나만 선택
   - Permissions → Repository permissions → **Contents: Read and write**
     (Metadata: Read-only는 자동으로 같이 켜집니다)
4. **Generate token** → 나온 `github_pat_...` 값을 바로 복사해 두세요. 이 화면을 벗어나면 다시 볼 수 없습니다.

> 토큰은 비밀번호처럼 다루세요. `index.html`에 붙여 넣거나 저장소에 올리지 마세요.
> 앱에 입력한 토큰은 그 기기 브라우저에만 저장됩니다.

## 4단계: 앱에서 연결하기 (기기마다 한 번)

1. 1단계 주소로 앱 접속 → 오른쪽 위 **동기화 설정**
2. GitHub 아이디, 데이터 저장소 이름(`wrongnote-data`), 토큰 입력 → **연결 테스트 후 저장**
3. "연결했습니다"가 나오면 끝. 위쪽 상태가 **GitHub에 저장됨 · 시각**으로 바뀝니다.
4. 휴대폰 등 다른 기기에서도 같은 주소로 접속해 같은 값을 입력하세요. 두 기기에 따로 쓴 기록은 합쳐집니다.

### 동작 방식

- 기록을 고치면 약 1초 뒤 GitHub에 저장됩니다.
- 앱 화면으로 다시 돌아오면 다른 기기에서 쓴 기록을 받아옵니다. 바로 받고 싶으면 **동기화 설정 → 지금 동기화**.
- 두 기기에서 같은 기록을 동시에 고치면 나중에 고친 쪽이 남습니다.
- 지난 기록은 `wrongnote-data` 저장소의 `wrongnote.json` → **History**에서 볼 수 있습니다.

## 새 버전으로 바꿀 때

`wrongnote` 저장소에서 `index.html`을 새 파일로 다시 올리면(**Add file → Upload files** → 같은 이름으로 덮어쓰기 → **Commit changes**) 1~2분 뒤 반영됩니다.
기록은 브라우저와 `wrongnote-data` 저장소에 있으므로 그대로 남습니다. 예전 버전에서 쓴 기록은 **생물 내용학**의 "단원 미지정"에 모여 있으니 **수정**을 눌러 단원을 골라 주세요.

## 문제가 생기면

| 화면 메시지 | 확인할 것 |
|---|---|
| 토큰이 잘못됐거나 만료됐습니다 | 3단계로 새 토큰을 만들어 동기화 설정에 다시 입력 |
| 토큰 권한이 부족합니다 | 토큰의 Repository access에 `wrongnote-data`가 있는지, Contents가 Read and write인지 |
| 저장소를 찾을 수 없습니다 | 아이디·저장소 이름 철자, 토큰이 그 저장소를 선택했는지 |
| ~는 공개 저장소입니다 | 데이터 저장소를 Private으로 바꾸기 (Settings → 맨 아래 Change visibility) |
| 오프라인 · 이 기기에 저장됨 | 인터넷이 연결되면 자동으로 올라갑니다 |

공용 컴퓨터에서 썼다면 다 쓴 뒤 **동기화 설정 → 연결 해제**를 눌러 토큰을 지우세요. 토큰을 잃어버렸거나 노출됐다면 3단계 화면에서 그 토큰을 **Delete**하고 새로 만들면 됩니다.
